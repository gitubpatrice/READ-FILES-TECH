Read Files Tech is a Swiss army knife for the files on your Android phone: a file manager, a universal viewer, editors, a document scanner, OCR, an encrypted vault and a set of file tools. Everything runs on the phone: the app has no internet permission.

<b>Features</b>

<ul>
<li>File manager — browse, search, sort, select several, rename, copy, move, a trash with undo, and APK installation handed to Android's installer</li>
<li>Viewer — text and code, Markdown, JSON, HTML, CSV, spreadsheets (XLSX, XLS, ODS), documents (DOCX, ODT, ODP), EPUB, PDF, ZIP, images</li>
<li>Editors — code and text with an automatic history of versions, CSV as an editable table</li>
<li>Document scanner — edges found, perspective straightened, saved as a PDF</li>
<li>OCR on the phone (Tesseract), in English, French, German, Italian and Spanish</li>
<li>Encrypted vault — AES-256-GCM, a key derived from your password by Argon2id, locked automatically</li>
<li>Panic mode, in Settings: erases at once what the app keeps, the vault included</li>
<li>Conversion — images to PDF, CSV to XLSX, text to PDF, PDF and DOCX to text, images to JPG or PNG</li>
<li>Photos — smaller images, and the location, date and camera model removed before you share one</li>
<li>Global search by name and by content, duplicates found by SHA-256, bulk rename with regular expressions</li>
<li>Tools — color picker, compare two files, file hash, encodings, formatting, ZIP creation, text and CSV tools</li>
<li>Quick settings tiles for the scanner, OCR and the vault</li>
<li>In English, French, German, Italian and Spanish</li>
</ul>

<b>Privacy</b>

<ul>
<li>No internet permission: the app cannot connect to anything, and its build checks it. No account, no analytics, no advertising, no tracking</li>
<li>No Google service: OCR and the scanner are free software running inside the app</li>
<li>All-files access is asked because a file manager needs it; nothing is read or written in the background</li>
<li>Sending a file to a cloud app is always your action: from the file's menu, or through Android's share sheet</li>
<li>Updates: About opens the releases page in your browser</li>
<li>Free software under the Apache License 2.0 — https://github.com/gitubpatrice/READ-FILES-TECH</li>
</ul>
