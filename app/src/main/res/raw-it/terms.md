# Condizioni d'uso — Read Files Tech

_Ultimo aggiornamento: 24 ottobre 2026 (versione 3.0.0)_

## Oggetto

Read Files Tech è uno strumento per leggere, modificare, convertire, cercare, proteggere e ordinare i Suoi file, che funziona sul Suo telefono. Queste condizioni ne regolano l'uso; usare l'app significa accettarle.

## Le Sue responsabilità

- Usare l'app solo con file che possiede o che è autorizzato a leggere, modificare, convertire o condividere; rispettare il diritto d'autore, la vita privata altrui e le leggi applicabili.
- Verificare un risultato prima di fidarsene o di diffonderlo: il riconoscimento del testo (OCR) può sbagliare, una conversione può perdere la formattazione, i bordi rilevati in una scansione possono essere imprecisi.
- Conservare i propri backup, soprattutto prima di modificare, spostare o rinominare molti file.
- Proteggere il telefono: blocco dello schermo, aggiornamenti di sicurezza.

## La cassaforte e la perdita di dati

- **Dimenticare la password della cassaforte rende i suoi file illeggibili per sempre**: non viene mai salvata, serve solo a derivare la chiave. Non esiste alcuna procedura di recupero. Lo stesso vale per la password di un backup `.rftvault`.
- La **modalità panico** cancella subito e definitivamente la cassaforte, le impostazioni, la cronologia e il cestino: **nessun recupero è possibile**, è voluto. Faccia prima un backup della cassaforte se vuole poterla ritrovare.
- Un file spostato nel **cestino** può essere ripristinato finché non lo ha svuotato. **Eliminare definitivamente**, svuotare il cestino e sostituire un file sono irreversibili.
- **Disinstallare l'app cancella la cassaforte**, che si trova nella sua memoria privata: ne faccia prima un backup, e verifichi che non sia in una cartella dell'app, cancellata anch'essa (la finestra del backup lo segnala).

## File di origine sconosciuta

- Resti prudente con i file ricevuti da fonti sconosciute. Il visualizzatore HTML mostra una pagina senza JavaScript e senza alcuna connessione, ma un file può comunque contenere un testo ingannevole.
- **Installare un APK** dall'esploratore è una Sua decisione: l'app ne mostra il nome, il pacchetto e la versione, poi lo affida al programma di installazione di Android, che chiede la propria conferma. Read Files Tech non verifica la provenienza di un APK.
